# skill_factory

A scaled-down, Uber-style platform for authoring, evaluating, measuring and improving agent skills.

- Design doc (English): [docs/DESIGN.en.md](docs/DESIGN.en.md)
- 設計文件（繁體中文）：[docs/DESIGN.zh-TW.md](docs/DESIGN.zh-TW.md)

Based on Uber Engineering's
[How Uber Evals 1 Million Agent Skill Invocations a Month](https://www.uber.com/us/en/blog/optimizing-ubers-agent-skills/)
and [Running a Software Factory Efficiently at Uber Scale](https://www.uber.com/us/en/blog/efficient-software-factory/).
